# MeteoSwiss — Home Assistant Integration

Custom Home Assistant integration for [MeteoSwiss](https://www.meteoswiss.admin.ch) open data. Provides current observations, local forecasts, weather warnings, precipitation radar, pollen, UV and lightning for any location in Switzerland.

**Status:** Under active development.
